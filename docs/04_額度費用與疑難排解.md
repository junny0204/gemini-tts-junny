# 額度、費用與疑難排解

## 免費版和付費版

| | 免費版 | 付費版（Tier 1 以上） |
|---|---|---|
| gemini-3.8-flash-tts 請求數 | 約每天 10 次、每分鐘 3 次（2026-11 在 AI Studio 看到的數字） | 高很多，以 AI Studio 顯示為準 |
| 怎麼算 | 每次請求算 1 次，不論文字多短 | 依語音長度扣預付金 |
| 費用 | 免費 | 2026 年底前每 10 秒語音約 US$0.00225（約 NT$0.07）；2027 年起加倍 |
| 內容是否用來改善 Google 產品 | 可能會（也可能有人工審閱） | 不會 |
| 重置時間 | 美國太平洋時間午夜（台灣 16:00；美國夏令時間期間 15:00） | 同左（有每日上限時） |

- 額度是按 **Google 專案**計算，不是按金鑰，也不是按電腦。兩台電腦用同一把金鑰，就共用同一份額度和預付金。
- 實際上限請看 https://aistudio.google.com/rate-limit ；Google 公布的文件沒有列出每個模型的免費額度，數字可能改變。
- 這個工具的 `used_today` 只計算**這台電腦**成功送出的次數，只是參考。
- **不要**用多個 Google 帳號輪流換金鑰來增加免費額度：這違反 Google API 服務條款（不得規避使用上限），可能導致帳號被停用。常用的話請開通付費（見 01 第 7 步）。

## 常見錯誤

| 看到的訊息 | 意思 | 怎麼辦 |
|---|---|---|
| 找不到 Gemini API Key | 環境變數 `GEMINI_API_KEY` 沒設定，或設定還沒儲存 | 照 02（Windows）或 03（Mac）設定；Windows 用方法 B 時記得主視窗要再按一次「確定」 |
| API Key 無效（400） | 金鑰複製不完整或貼錯 | 重新複製整把金鑰，再設定一次 |
| 需要驗證專案（403，FREE_TIER_VERIFICATION_REQUIRED） | Google 要求驗證這個專案 | 照 01 第 6 步用手機掃 QR code |
| 金鑰被判定外洩（reported as leaked） | 金鑰已被 Google 停用 | 建立新金鑰，重新設定（見 01「金鑰外流了怎麼辦」） |
| 沒有權限（401／403） | 金鑰被停用、帳單逾期，或不是 AI Studio 的 Gemini 金鑰 | 到 https://aistudio.google.com/apikey 檢查；必要時建立新金鑰 |
| 每分鐘上限（429） | 太快送出太多請求 | 工具會自動等待重試；仍失敗就等一分鐘 |
| 今天的免費額度已用完 | 免費版每日上限到了 | 等重置時間（訊息會寫幾點）、開通付費，或改用 Lite 模型 |
| 付費帳號的每日上限 | 付費等級也有每日上限 | 等重置，或到 rate-limit 頁面查看上限 |
| 預付餘額已用完（402） | 付費帳號沒錢了 | 到 https://aistudio.google.com/billing 儲值 |
| 超過 150 秒沒有回應 | Google 伺服器暫時異常（不是額度問題） | 稍後再試 |
| 這個地區不提供 Gemini API（location is not supported） | Google 沒有在你所在的地區開放 Gemini API | 不是金鑰的問題，換金鑰沒有用；請改在支援的地區使用 |
| 找不到模型（404） | 模型名稱錯誤或套件版本不對 | 重新執行安裝程式 |

## 安裝相關

| 狀況 | 怎麼辦 |
|---|---|
| 找不到 Python 3.11 以上 | Windows：請 Claude 執行 `winget install -e --id Python.Python.3.13 --scope user --accept-source-agreements --accept-package-agreements`，或自己到 https://www.python.org/downloads/ 依網頁指示安裝。Mac：到 https://www.python.org/downloads/macos/ 下載 Python 3.13.x 的安裝程式（已測試的版本），或 `brew install python@3.13`。裝好後請 Claude 重新安裝。Mac 跳出「需要安裝命令列開發者工具」的視窗時，按「取消」即可（不需要它） |
| 套件安裝失敗 | 多半是網路中斷，請 Claude 重新執行安裝程式 |
| 重開 Claude 後看不到 gemini-tts 工具 | 在 Claude 的輸入框打 `/mcp`，看 `gemini-tts` 有沒有出現、是否已連線；沒有的話請 Claude 重新執行安裝程式（它會自動找到桌面 App 內建的 `claude` 指令來註冊） |
| 換了新金鑰，Claude 好像還在用舊的 | Claude 啟動時會記住當時的環境變數。工具本身會優先讀你剛存的新金鑰，但請找時間**完全結束** Claude 再打開，讓所有地方都一致 |
| 安裝或移除時出現 WinError 5／32（檔案被鎖住） | Claude 正在使用舊版的檔案。請 Claude 先給你一行 PowerShell 指令（結果裡的 `rerun_powershell`），然後完全結束 Claude、打開 PowerShell 貼上執行，完成後再打開 Claude |
| Claude 還在用舊版 | 要**完全結束** Claude 再打開（Windows：系統匣圖示 → 結束；Mac：Cmd+Q） |
| Windows 上中文變亂碼 | 執行 Python 時加 `-X utf8`；或在 PowerShell 先執行 `[Console]::OutputEncoding = [Text.Encoding]::UTF8` |
| Mac 播放沒有聲音 | 工具用 macOS 內建的 afplay 播放；確認系統音量和輸出裝置 |
| Mac 雙擊 .command 顯示「無法打開」 | 改在終端機執行 `bash ~/.claude/mcp-servers/gemini-tts/scripts/set-gemini-key.command` |

## 檔案放在哪裡

| 內容 | Windows | macOS |
|---|---|---|
| 程式、虛擬環境 | `%USERPROFILE%\.claude\mcp-servers\gemini-tts\` | `~/.claude/mcp-servers/gemini-tts/` |
| Skill | `%USERPROFILE%\.claude\skills\gemini-tts\SKILL.md` | `~/.claude/skills/gemini-tts/SKILL.md` |
| 免費／付費設定 | 上面程式資料夾裡的 `settings.json` | 同左 |
| 本機使用次數紀錄（不含金鑰） | 上面程式資料夾裡的 `usage.json` | 同左 |
| 舊版備份 | 上面程式資料夾裡的 `backup_v版本_時間\` | 同左 |
| 產生的語音（預設） | `%USERPROFILE%\Music\GeminiTTS\` | `~/Music/GeminiTTS/` |
| 金鑰 | 使用者環境變數 `GEMINI_API_KEY` | `~/.zshenv`（bash 使用者：bash 登入時讀的設定檔，通常是 `~/.bash_profile`） |
